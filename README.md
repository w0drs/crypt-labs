# CryptLabs

Лабораторные работы по дисциплине: "Методы и средства криптографической защиты информации"

## Реализованные алгоритмы

- **Шифр Цезаря** — сдвиг каждой буквы на заданное число позиций. Ключ — целое число от 1 до 25 для английского алфавита или от 1 до 32 для русского.
- **Шифр Виженера** — сдвиг букв по циклически повторяемому ключевому слову. Ключ должен содержать только буквы выбранного алфавита.
- **Перестановочный шифр** — перестановка символов внутри блоков. Ключ — числа от 1 до размера блока без повторов, например `3,1,4,2`.

Цезарь и Виженер поддерживают английский и русский алфавиты (включая `ё`),
сохраняют регистр и не изменяют символы вне выбранного алфавита.
Перестановочный шифр удаляет обычные пробелы и дополняет неполный блок символами `x`.

Эти шифры предназначены для обучения, а не для защиты реальных данных.

## Запуск из консоли

Откройте терминал в папке проекта. Дополнительные библиотеки устанавливать не нужно.

Общий формат команды:

```bash
python main.py <алгоритм> <действие> [параметры]
```

Алгоритмы: `caesar`, `vigenere`, `permutation`.

Действия:
- `encrypt` — зашифровать текст.
- `decrypt` — расшифровать текст.
- `check` — зашифровать, расшифровать и проверить совпадение с исходным текстом.

Параметры:
- `--text` — текст; если не указан, программа запросит его.
- `--key` — ключ; если не указан, программа запросит его.
- `--alphabet en` или `--alphabet ru` — алфавит для Цезаря и Виженера. По умолчанию `en`.
- `--original-length` — длина исходного текста без пробелов для удаления дополнения при расшифровании перестановочным шифром.

### Ввод текста и ключа по запросу

```bash
python main.py caesar check
python main.py vigenere check --alphabet ru
python main.py permutation check
```

После запуска введите текст и ключ в ответ на запросы `Text:` и `Key:`.
Ключ перестановки вводится через запятые или пробелы: `3,1,4,2` или `3 1 4 2`.

### Шифр Цезаря

Шифрование английского текста:

```bash
python main.py caesar encrypt --text "hello" --key 3
```

Результат: `khoor`.

Расшифрование:

```bash
python main.py caesar decrypt --text "khoor" --key 3
```

Результат: `hello`.

Проверка русского текста:

```bash
python main.py caesar check --alphabet ru --text "яблоко" --key 3
```

Шифротекст: `вдоснс`. После расшифрования получится `яблоко`.

### Шифр Виженера

```bash
python main.py vigenere encrypt --alphabet ru --text "криптография" --key "шифр"
```

Результат: `гщэакччбшээп`.

```bash
python main.py vigenere decrypt --alphabet ru --text "гщэакччбшээп" --key "шифр"
```

Результат: `криптография`.

### Перестановочный шифр

```bash
python main.py permutation check --text "crypto is good" --key "3,1,4,2"
```

Шифротекст: `ycpritsoogdo`. После расшифрования получится `cryptoisgood`.
Проверка выполняется с исходным текстом без пробелов, поскольку они удаляются перед шифрованием.

Если последний блок неполный, он дополняется символами `x`:

```bash
python main.py permutation encrypt --text "ab x" --key "3,1,4,2"
```

Результат: `xaxb`. Для удаления только добавленных символов передайте длину исходного текста **без пробелов**:

```bash
python main.py permutation decrypt --text "xaxb" --key "3,1,4,2" --original-length 3
```

Результат: `abx`. Без `--original-length` получится `abxx`: программа оставит
заполнитель, поскольку не может отличить его от настоящего `x` в конце текста.
В режиме `check` исходная длина учитывается автоматически.
